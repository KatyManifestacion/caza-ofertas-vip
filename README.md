# Caza Ofertas VIP

Sitio público de https://cazaofertas.vip. Se actualiza automáticamente cada mañana desde la página de administración en Claude.

## Fotos ligeras
Antes de cada publicación se corre `python3 tools/sitio_ligero.py`: saca las fotos incrustadas de `index.html` a la carpeta `fotos/` para que la página cargue rápido en celular.
